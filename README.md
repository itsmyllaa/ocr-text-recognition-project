# Reconhecimento de Texto com Azure Cognitive Services

Este projeto utiliza a API de Reconhecimento de Texto (OCR) do Azure Cognitive Services para extrair texto de imagens.

## Como usar

### Pré-requisitos
- Conta no Azure
- Chave da API e URL do serviço de **Computer Vision** do Azure
